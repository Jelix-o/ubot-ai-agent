# UBot 后台设计依据

参考图由服务器配置的 `gpt-image-2.5-sunburst` 生成，独立页面均为 1536×1024、高质量 PNG。完整提示词保存在 `prompts.jsonl`。图片是布局参考，示例数字和生成图中不存在的业务字段不进入产品。

## 共同规范

- 240px 白色侧栏，仅展示六个工作区；当前工作区使用浅青绿背景和左侧强调线。可折叠，手机使用抽屉。
- 顶栏高 64px，提供工作区面包屑、当前群、搜索和账号。正文 24px 间距，标题约 28px；工作区标签使用下划线。
- 背景 #f5f7f8，表面白色，边线 #e3e8e8，文字 #172b2b，主色 #0f766e。深色使用 #111718 / #192223 和 #5eead4。
- 控件约 38px 高，8px 圆角；表格采用浅灰表头、细分隔线，状态色有文字标签，数值使用等宽数字。
- 右侧详情与编辑抽屉约 420px 宽，标题和操作固定，主体滚动；手机占满屏幕。所有确认框支持键盘、焦点返回和 Escape。
- 选中项使用统一批量操作栏，执行前展示逐项目标与变更，任务中心展示结果。

## 页面实现映射

| 参考 | 实现决定 |
|---|---|
| overview / dark-overview | 四个真实指标，最近记忆、服务状态和快捷入口；不添加虚构增长率 |
| groups | 回复、能力、权限、排程四个标签；保留真实回复模型、参与方式、触发词、排程日期规则 |
| members | 列表与详情抽屉；备注、身份、隐私退出、明确记忆统一入口 |
| memories / knowledge | 筛选、表格、分页、选择与批量预览；FAQ 和企业排名保留各自权限 |
| html-previews / memes | 图片与网页浏览保留；受保护素材禁选，详情单独展示 |
| persona / commands | 结构化表单和指令详情，不增加虚构人格或指令 |
| tasks / audit | 可展开详情、进度、逐项结果和取消；不增加广播等不存在的任务类型 |
| settings / health / security | 模型和运行策略分开，真实健康数据、账号权限和近期验证保留 |
| analytics | 真请求指标、北京时间趋势、用量覆盖率、按币种实际费用和请求明细 |
| bulk-preview | 来源群、目标群、字段选择及逐项差异；排除身份、名单和隐私数据 |

初始 login 和 mobile 图错误地带有已登录导航或设备编辑器，因此另生成 login-v2 / mobile-v2，以无导航登录和实际手机界面为准。中文与字段均以现有服务端功能为准。
